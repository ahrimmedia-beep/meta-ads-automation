# Meta Ads automation

Command line tool that manages a Meta ad account through the Marketing API, so an AI agent or a script can build and check campaigns.

## What it does

- Creates campaigns, ad sets, ads and creatives.
- Everything is created paused. Turning ads on needs an explicit confirm flag, and every create command has a dry run.
- Pulls insights and spend.
- Publishes Instagram Reels through the Graph API.

## Stack

Python, Meta Marketing API, Instagram Graph API.
